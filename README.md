# HISTORICAL GOLD PRICE

Global Gold Price Analysis & Visualization

A Power BI data analytics project focused on analyzing historical gold prices,
identifying long-term trends, price movements, and key market patterns.

---

## Project Overview

This project analyzes historical gold price data using Power BI and Excel
to transform raw historical data into an interactive analytical dashboard.

The dashboard provides insights into gold price trends across different
periods and helps users understand historical market movements through
interactive visualizations.

---

- Power BI

- Data Visualization
- Data Cleaning & Transformation

## Key Analysis

The project focuses on:

- Historical gold price trends
- Year-over-year price movements
- Average gold price

- Price changes over time
- Long-term market trends
- Interactive filtering and exploration
